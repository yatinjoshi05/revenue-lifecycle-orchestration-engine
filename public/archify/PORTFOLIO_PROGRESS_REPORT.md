## 1. Architecture Portfolio Deployment Architecture

To ensure zero regression against the live Vite 6 / React 18 dashboard application, the Archify portfolio is integrated into both:
1. `archify/` (Repository Root): Pure source documentation artifacts, JSON candidates, and evidence reports.
2. `public/archify/` (Static Assets for Vite): Automatically bundled by `vite build` into `dist/archify/` during the GitHub Actions deployment workflow (`.github/workflows/deploy.yml`).

This architecture delivers:
- **Root URL:** `https://yatinjoshi05.github.io/revenue-lifecycle-orchestration-engine/` → Live Interactive Operator Dashboard (React 18 + Vite 6).
